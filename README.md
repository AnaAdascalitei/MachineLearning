# MachineLearning
Homeworks 1,2 and 3 from AI Course

HW1: Monte Carlo Tree Search for Connect Four
Implemented the UCT algorithm (Monte Carlo Tree Search) for Connect Four and compared agents with different computational budgets over multiple games.

HW2: Course Completion Prediction
End-to-end ML pipeline on ~100k online-learning records: EDA, missing-value imputation, one-hot encoding, scaling, PCA and SMOTE balancing. Compared 5 classifiers with stratified cross-validation (accuracy, F1, ROC-AUC).

HW3: Land-Cover Type Classification (Kaggle)
Multi-class classification (7 classes) with 43 engineered features. Compared 5 models and tuned tree ensembles; Extra Trees reached 89% validation accuracy, up from a 74% baseline.
